# Changelog

## 0.1.0 — 2026-10-20
- Serviço técnico independente com login exclusivo, sessões revogáveis e URL própria no Render.
- Explorador das 15 tabelas da API via views restritas, filtros, paginação, tipos, relações e detalhes JSON.
- Editor SELECT com política sintática, limite de tempo/linhas e exportação CSV.
- Consulta da auditoria da API e histórico append-only de operações do Admin.
- Script de provisionamento de papéis/views e validação PostgreSQL/Playwright em CI.
